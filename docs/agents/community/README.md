# Community agents

These are community-maintained troubleshooting agents. Each one subclasses `agent.base.DiagnosisAgent`, keeps its implementation under `src/agent/community/<name>/`, and is described on this page.

| Agent | CLI name | Reference | Implementation |
| --- | --- | --- | --- |
| SADE | `community.sade` | [SADE](sade.md) | [`src/agent/community/sade/`](../../../src/agent/community/sade/) |

For the agent contract, see [Integrate a custom agent](../custom-agents.md).
